# 🛠 Teksika

*Teksika* adalah aplikasi berbasis web yang memudahkan pengguna untuk mencari dan memesan jasa tukang profesional sesuai kebutuhan, mulai dari:
- Perbaikan listrik ⚡
- Plumbing / saluran air 🚰
- Service AC ❄
- Jasa cat rumah 🎨
- Dan berbagai jasa perbaikan lainnya 🏠

---

## 🚀 Fitur Utama
- 🔍 Cari jasa tukang sesuai kategori kebutuhan.
- 📝 Pesan jasa langsung melalui aplikasi.
- 💰 Admin memberikan penawaran harga & detail tukang.
- 📅 Pilih jadwal pengerjaan sesuai keinginan pengguna.
- 🛡 Tukang langsung datang setelah pembayaran terverifikasi.

---

## 📂 Struktur Aplikasi
- *Frontend*: (HTML/CSS/JS)
- *Backend*: (php,Laravel, Node.js)
- *Database*: (MySQL)



## 🖼 Alur Pemesanan
1. User memilih kategori jasa (listrik, AC, plumbing, dll).
2. User mengisi detail pesanan & jadwal.
3. Admin memberikan harga + detail tukang.
4. User melakukan pembayaran.
5. Tukang datang ke lokasi sesuai jadwal.
